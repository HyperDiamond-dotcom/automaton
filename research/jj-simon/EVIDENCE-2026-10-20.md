# JJ Simon NQ historical study — 20 October 2026

**Verdict: neither test strategy was profitable in either period. Do not trade live.**

This file records an actual deterministic Node.js replay executed on 20 October 2026 in an isolated tool sandbox, using the exact research branch engine and the third-party dataset named below. The dedicated offline test workflow was green prior to the timestamp-format correction; the historical GitHub Actions workflow was queued when this independent replay completed. Re-running the scripted analysis is required if implementation/data changes. These are *not* JJ Simon's verified strategy results.

## Interpretation
- Both strategies lost in the development and later holdout samples. Development runs halted trading after losses, so the later calendar period within the development window contains no new trades after the halt.
- JJ's account of fair-price reassessment, scheduled-news anchors, broader market bias and discretionary structure is not fully captured by fixed indicators in this experiment.
- The evaluation is based on OHLC candles, next-bar-open synthetic fills and a simplified ATR stop. Intra-minute sequencing, market liquidity and spreads are not known.
- No real or demo trades executed, no account purchases, no model or paid API costs, no changes to deployed Atlas.
- Recommended decision: **reject both implementations as trading systems**. Any next version needs a new preregistered definition and fresh genuinely unseen testing, not post-hoc optimisation of this holdout.
